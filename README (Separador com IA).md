# Separador de arquivos

Separa arquivos de texto ou planilhas em partições menores dividindo igualmente.

## 📋 Sobre o projeto

O projeto realiza a divisão igualitária de um arquivo, permitindo melhor controle da quantidade de informações, foi projetado utilizando Ia, para organização mais rápida para criação de relatórios no meu último emprego, uma quantidade enorme de números seriam enviados para disparar sms, porém teriamos que separar de pouco em pouco, usando esse programa a separação é realizada rápidamente, porém ainda sem conseguir escolher a quantidade de informações dentro de cada arquivo.

## ✨ Funcionalidades

- Primeira parte anexo de arquivo, ao clicar, abre uma tela do explorar arquivos e permite selecionar o arquivo de divisão, segundo item é o local de destino do arquivo, após a partição e o terceiro item permite escolher a quantidade de divisões do arquivo.

## 🛠️ Tecnologias

## ⚙️ Pré-requisitos

- Python 3.13

## ▶️ Como usar

Tem uma interface interativa, porém é necessário apenas subir o arquivo, colocar o destino da separação e quantidade, após isso é apenas clicar em separar arquivo e pronto, ele estará separado.
